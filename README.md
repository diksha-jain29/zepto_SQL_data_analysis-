# Zepto Sales Data Analysis Using PostgreSQL
## Objective:
The primary objective of this project is to demonstrate the application of SQL and data analysis techniques to a real-world sales dataset, moving from raw data to meaningful business insights by following the systematic Data Analysis process.
## Project Overview:
The project focuses on analyzing Zepto Sales Data using PostgreSQL to derive meaningful business insights from raw data. The analysis follows a structured data analytics workflow, beginning with data exploration, followed by data cleaning, analysing and business-oriented analysis and insights.  
The project demonstrates how SQL can be used to transform raw data into actionable information which can support better business decision-making.
## Analysis Process:
The analysis was carried out in the following stages:
1. DATA EXPLORATION: Identified relevant variables and assessed the overall quality of data.
2. DATA CLEANING: Checked and handled invalid records and standardized the data where required for reliable analysis.
3. DATA ANALYSIS: Running the SQL queries to identify trends and patterns.
4. BUSINESS INSIGHTS: Derived business insights from the cleaned data. Finding the best products, calculating revenue, grouping the categories based on criteria and other relevant business information.
